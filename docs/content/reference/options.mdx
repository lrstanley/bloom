This page lists what's available, grouped by what it's for. The full documentation, with every method's details,
is on [pkg.go.dev](https://pkg.go.dev/bloomfx.dev/bloom).

## Nodes

| Function | Makes |
| --- | --- |
| [`Row(children...)`](https://pkg.go.dev/bloomfx.dev/bloom#Row) | children left to right |
| [`Column(children...)`](https://pkg.go.dev/bloomfx.dev/bloom#Column) | children top to bottom |
| [`Grid(cols, children...)`](https://pkg.go.dev/bloomfx.dev/bloom#Grid) | equal-width columns, filled row by row |
| [`Wrap(children...)`](https://pkg.go.dev/bloomfx.dev/bloom#Wrap) | children flowing onto new lines at their natural sizes |
| [`Text(s)`](https://pkg.go.dev/bloomfx.dev/bloom#Text) | a string, optionally styled |
| [`Marquee(s, phase)`](https://pkg.go.dev/bloomfx.dev/bloom#Marquee) | one line that scrolls, or is cut short, when it doesn't fit |
| [`Skeleton(lines...)`](https://pkg.go.dev/bloomfx.dev/bloom#Skeleton) | placeholder bars for content still loading, a line for each width, 0 for a blank line |
| [`Box(style, child)`](https://pkg.go.dev/bloomfx.dev/bloom#Box) | a Lip Gloss frame around a child |
| [`Centered(child)`](https://pkg.go.dev/bloomfx.dev/bloom#Centered) | a child at its natural size in the middle of its space |
| [`MinSize(w, h, child)`](https://pkg.go.dev/bloomfx.dev/bloom#MinSize) | a child, or a note that the window is too small below `w`×`h` |
| [`Scroll(child, offset)`](https://pkg.go.dev/bloomfx.dev/bloom#Scroll) | a child shown from row `offset`; `.X(offset)` scrolls it sideways too |
| [`Scrollbar(total, visible, offset)`](https://pkg.go.dev/bloomfx.dev/bloom#Scrollbar) | a vertical scrollbar, drawn while there's more to scroll to |
| [`ScrollbarOf(id)`](https://pkg.go.dev/bloomfx.dev/bloom#ScrollbarOf) | a scrollbar following the `Scroll` the node with ID `id` is in, or the `List` or `Viewport` with ID `id` |
| [`List(count, item)`](https://pkg.go.dev/bloomfx.dev/bloom#List) | the items of a list that fit, built by `item(i)` only for those; `.Offset(i)`, `.Keep(i)`, `.Gap(n)` |
| [`Viewport(buf)`](https://pkg.go.dev/bloomfx.dev/bloom#Viewport) | the lines of a [`Buffer`](https://pkg.go.dev/bloomfx.dev/bloom#Buffer) in sight, from a position kept in the model, drawing only those |
| [`Overlay(base, layers...)`](https://pkg.go.dev/bloomfx.dev/bloom#Overlay) | layers drawn over a base |
| [`Layer(child)`](https://pkg.go.dev/bloomfx.dev/bloom#Layer) | a layer for an overlay, centered at its natural size |
| [`Transition(t, child, effects...)`](https://pkg.go.dev/bloomfx.dev/bloom#Transition) | a child drawn with effects at progress `t` |
| [`Present(p, child, effects...)`](https://pkg.go.dev/bloomfx.dev/bloom#Present) | a child shown only while a presence is visible |
| [`Drawable(d)`](https://pkg.go.dev/bloomfx.dev/bloom#Drawable) | an Ultraviolet `Drawable`, painting cells directly |

Any value with a `View() string` method can also be a child.

## Container options

| Method | On | Does |
| --- | --- | --- |
| `Gap(n)` | `Row`, `Column` | `n` cells between children |
| `Gap(x, y)` | `Grid`, `Wrap` | space between columns and between rows |
| `Align(a)` | `Row`, `Column` | cross-axis placement of children: `Stretch` (default), `Start`, `Center`, `End` |
| `Justify(j)` | `Row`, `Column` | main-axis placement when nothing grows: `flex.Start`, `Center`, `End`, `SpaceBetween`, `SpaceAround`, `SpaceEvenly` |

## Box options

| Method | Does |
| --- | --- |
| `Edge(side, align, child)` | draws a child over a side of the border, such as a title, an icon button, or a scrollbar; a `Text` on the left or right runs down the side |
| `EdgeAt(side, at, child)` | draws a child at cell `at` along a side, corners included, counting back from the far end when negative; for joining lines to the border |
| `BorderFx(t, effects...)` | applies effects to the frame only, such as the looping [border effects](/reference/effects#borders) |

## Scrollbar options

| Method | Does |
| --- | --- |
| `Horizontal()` | one row tall, for content scrolled sideways |
| `OnScroll(fn)` | drag the thumb, or click to jump, calling `fn` with the offset to scroll to |
| `Style(bloom.ScrollbarStyle{...})` | how the thumb, the part in view, and the track, the rest, look; no track glyph leaves what's beneath |
| `HoverStyle(bloom.ScrollbarStyle{...})` | how it looks while hovered or dragged, in place of `Style`; none by default, so it looks the same |

## Viewport options

See [Viewports](/layout/viewports).

| Method | Does |
| --- | --- |
| `At(pos)` | where it's scrolled to: a `ViewportPos` of the line at the top, the rows of it above, and columns sideways; `ViewportEnd` is the end |
| `Wrap(mode)` | `WrapNone` (default, scrolled sideways), `WrapWords`, or `WrapChars` |
| `Follow()` | stay at the end as lines are appended, while it's there |
| `OnScroll(fn)` | the wheel, a `ScrollbarOf` it, and selecting past its edge scroll it, calling `fn` with the position |
| `LineNumbers(style)`, `Gutter(width, fn)` | columns beside the lines: their numbers, or what `fn` returns for each row |
| `Marks(fn)`, `MarkMatches(re, style)` | parts of the lines in sight drawn in styles of their own, such as matches of a search |
| `Style(style)` | colors and attributes for all of its rows, under the lines' own; put it in a `Box` for padding |
| `LineStyle(fn)` | a style for each line in sight, across the whole row, under its own |
| `Selectable()` | [select its text with the mouse](/input/selection), all of it, with wrapped rows joined |
| `Trusted()` | keep the commands in its lines meant for the terminal, such as images, which are dropped otherwise |

| `Buffer` method | Does |
| --- | --- |
| `NewBuffer(s)`, `SetContent(s)`, `SetLines(lines...)`, `Clear()` | replace or remove the lines |
| `Append(lines...)` | add lines, measuring only them |
| `Len()`, `Line(i)`, `Text(i)`, `String()` | read lines back, with or without their styles |
| `Find(re, line, at)`, `FindBefore(re, line, at)` | the next or previous match of a regular expression |

## Slots

| Function | Size |
| --- | --- |
| `Fixed(n, child)` | exactly `n` cells; a `nil` child is empty space |
| `Auto(child)` | the child's natural size |
| `Fill(child)` | an equal share of what's left |
| `Grow(weight, child)` | a weighted share of what's left |
| `Percent(p, child)` | `p`% of the container |
| `Space()` | empty space that fills what's left |

| Method | Does |
| --- | --- |
| `Min(n)`, `Max(n)` | clamp the size on the main axis |
| `Collapsible(priority)` | allow dropping the slot when minimums don't fit, lowest priority first |
| `Align(a)` | this slot's cross-axis placement |
| `ID(id)` | the ID for focus, layout animation, and `Frame.Rect` |
| `On(handlers...)` | [mouse handlers](/input/mouse) from the `on` package |
| `Focusable()` | a stop in the focus order |
| `Scope()` | a focus scope, for `Focus.Within` and `Focus.Push` |
| `Animate(opts...)` | glide to new positions and sizes; needs an ID and a `Root` |

## Text

| Method | Does |
| --- | --- |
| `Style(style)` | render with a Lip Gloss style at the node's size, wrapping long lines |
| `Truncate()` | one line, cut short with "…" |
| `Cursor(c)` | show the terminal cursor at `c`, relative to the node |
| `HoverStyle(style)` | render with `style` while the pointer is over the node |
| `Trusted()` | keep the commands in the text meant for the terminal, such as images, which are dropped otherwise |
| `ID(id)`, `Focusable()`, `On(handlers...)` | as for slots |

Boxes, rows, columns, grids, and wraps have `ID(id)` and `On(handlers...)` too, and boxes have `HoverStyle(style)`
for their frame.

Text, boxes, rows, columns, grids, slots, layers, lists, and viewports have `Selectable()`, which lets the mouse
[select their text](/input/selection).

`Marquee` has `Style(style)` and `Gap(s)`, the text shown between loops. `Skeleton` has `Style(style)`, which
colors the bars, and `Shimmer(phase)`, which sweeps a band of light across them.

## Layers

| Method | Does |
| --- | --- |
| `Anchor(x, y)` | place on each axis: `Start`, `Center` (default), `End` |
| `AnchorTo(id, side)` | place against a side of another node |
| `Offset(x, y)` | move from where it's anchored |
| `Size(w, h)` | set the size; zero uses the natural size |
| `Margin(n)` | stay `n` cells from the screen's edges |
| `Modal()` | take every mouse event from what's beneath, and be a focus scope |
| `Backdrop(effects...)` | apply effects to everything beneath |
| `Shadow(x, y, effects...)` | apply effects beneath, offset like a drop shadow |
| `Presence(p, effects...)` | show while a presence is visible, with effects |
| `Transition(t, effects...)` | draw with effects at progress `t` |
| `ID(id)` | the ID for focus, anchoring, layout animation, and `Frame.Rect` |
| `On(handlers...)` | mouse handlers; `on.ClickOutside` runs for a modal layer's backdrop |
| `Animate(opts...)` | glide to new positions and sizes; needs an ID and a `Root` |

## Root

| | Does |
| --- | --- |
| `bloom.New(opts...)` | make a root; keep it in your model by pointer |
| `ui.Init()` | ask the terminal for its colors; return from `Init` |
| `ui.Update(msg)` | hear the terminal, run layout animation, and keep hover up to date; pass every message, return the command |
| `ui.View(w, h, tree)` | lay out, draw, and return a `tea.View` that runs mouse handlers |
| `ui.Render(w, h, tree)` | lay out and draw to a string; a height of zero uses the natural height |
| `ui.Frame()` | the geometry of the last frame drawn |
| `ui.Click(id)`, `ui.ClickAt(x, y)` | run the handlers for a click, for tests |
| `ui.Selection()`, `ui.SelectAll(id)`, `ui.ClearSelection()` | read, select all of a node, or clear the [text selected with the mouse](/input/selection) |
| `ui.CopySelection()` | copy the selection with OSC 52 and `WithClipboard`; `nil` when nothing is selected |

### Root options

| Option | Default | Sets |
| --- | --- | --- |
| [`WithColors(fg, bg)`](https://pkg.go.dev/bloomfx.dev/bloom#WithColors) | white on black | the terminal colors effects blend with, until the terminal reports its own |
| [`WithFPS(n)`](https://pkg.go.dev/bloomfx.dev/bloom#WithFPS) | 60 | the frame rate of layout animation |
| [`WithUnfocusedFPS(n)`](https://pkg.go.dev/bloomfx.dev/bloom#WithUnfocusedFPS) | 20 | the frame rate of layout animation while the terminal isn't focused |
| [`WithWidthMethod(m)`](https://pkg.go.dev/bloomfx.dev/bloom#WithWidthMethod) | `ansi.GraphemeWidth` | how character widths are measured; must match the terminal |
| [`WithClock(now)`](https://pkg.go.dev/bloomfx.dev/bloom#WithClock) | `time.Now` | the clock for layout animation and double clicks, for tests |
| [`WithFocus(&m.focus)`](https://pkg.go.dev/bloomfx.dev/bloom#WithFocus) | none | the focus that clicks move, before handlers run |
| [`WithSelectionStyle(style)`](https://pkg.go.dev/bloomfx.dev/bloom#WithSelectionStyle) | a tinted background | how text selected with the mouse is drawn |
| [`WithWordChars(chars)`](https://pkg.go.dev/bloomfx.dev/bloom#WithWordChars) | `@-./_~?&=%+#` | the characters a double click takes into a word, besides letters and digits |
| [`WithClipboard(write)`](https://pkg.go.dev/bloomfx.dev/bloom#WithClipboard) | none | a system clipboard `CopySelection` writes to, besides OSC 52 |
| [`WithCopyFlash(on)`](https://pkg.go.dev/bloomfx.dev/bloom#WithCopyFlash) | on | whether a copy sweeps a band across the text copied |
| [`WithClickDelay(on)`](https://pkg.go.dev/bloomfx.dev/bloom#WithClickDelay) | on | whether clicks in selectable nodes wait to tell them from a double click |

## Geometry and input

| | Does |
| --- | --- |
| [`Solve(w, h, tree)`](https://pkg.go.dev/bloomfx.dev/bloom#Solve) | lay out without drawing, and return the `*Frame` |
| [`Render(w, h, tree)`](https://pkg.go.dev/bloomfx.dev/bloom#Render) | lay out and draw to a string, without a root |
| `frame.Rect(id)` | where a node went, and whether it's in the frame |
| `frame.Hit(x, y)` | the IDs of the nodes at a point, outermost first |
| `frame.Viewport(id)`, `frame.List(id)` | where a [viewport](/layout/viewports) or [list](/layout/lists) was scrolled to, and how much it showed |
| [`ThrottleMouse(every)`](https://pkg.go.dev/bloomfx.dev/bloom#ThrottleMouse) | a `tea.WithFilter` filter that drops wheel and motion events that come too fast |
| `Focus[K]` methods | `Set`, `Clear`, `Is`, `Current`, `Next`, `Prev`, `Update`, `Push`, `Pop`, `Scope`, `Within`; `K` is the type of the IDs focus moves between |

## Mouse handlers

From [`bloomfx.dev/bloom/on`](https://pkg.go.dev/bloomfx.dev/bloom/on), for `On(...)`:

| Handler | Runs on |
| --- | --- |
| `on.Click(fn)`, `on.RightClick(fn)`, `on.MiddleClick(fn)` | a click with that button, when it comes up over the node |
| `on.DoubleClick(fn)` | the second of two left clicks within 400ms |
| `on.Press(fn)` | a left click, or enter or space while focused |
| `on.ClickAt(fn)`, `on.RightClickAt(fn)` | a left or right click, with an `on.Event` holding where |
| `on.Scroll(fn)` | the wheel, as `dx, dy` |
| `on.Hover(fn)` | the pointer moving onto or off the node |
| `on.Drag(fn)` | a left-button drag that starts on the node, until the button comes up |
| `on.ClickOutside(fn)` | a button going down anywhere else; a modal layer's backdrop |
| `on.Mouse(fn)` | every mouse event over the node |
| `on.Msg(msg)` | a handler function that sends `msg` to `Update` |

Component interfaces: [`Measurer`](https://pkg.go.dev/bloomfx.dev/bloom#Measurer) reports a natural size,
and [`Layouter`](https://pkg.go.dev/bloomfx.dev/bloom#Layouter) builds a layout for the space given. The
handlers a `Layouter` makes can call `ctx.Frame()` when they run to read the frame on screen.

## Animation options

For `anim.NewValue`, `anim.NewPresence`, `anim.NewLoop`, `Sequence.With`, `anim.To`, and `Animate`:

| Option | Default | Sets |
| --- | --- | --- |
| [`Duration(d)`](https://pkg.go.dev/bloomfx.dev/bloom/anim#Duration) | 250ms | how long easing to a target takes |
| [`Ease(e)`](https://pkg.go.dev/bloomfx.dev/bloom/anim#Ease) | `OutCubic` | the easing curve |
| [`Spring(frequency, damping)`](https://pkg.go.dev/bloomfx.dev/bloom/anim#Spring) | | move like a spring instead of easing |
| [`FPS(n)`](https://pkg.go.dev/bloomfx.dev/bloom/anim#FPS) | 60 | frames requested while animating |
| [`UnfocusedFPS(n)`](https://pkg.go.dev/bloomfx.dev/bloom/anim#UnfocusedFPS) | 20 | frames requested while the terminal isn't focused |
| [`Clock(now)`](https://pkg.go.dev/bloomfx.dev/bloom/anim#Clock) | `time.Now` | the source of time, for tests |

Easings: `Linear`, `InQuad`, `OutQuad`, `InOutQuad`, `OutCubic`, `InOutCubic`, `OutBack`, or any
`func(float64) float64`.

Sequence steps: `To(target, opts...)`, `Hold(d)`, `Jump(target)`.
