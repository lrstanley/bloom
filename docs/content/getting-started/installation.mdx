## Requirements

- **Go 1.27** or newer. bloom uses generic methods, such as `frame.Rect[K]`, which need it.
- **[Bubble Tea v2](https://github.com/charmbracelet/bubbletea)**, imported as `charm.land/bubbletea/v2`.
- **[Lip Gloss v2](https://github.com/charmbracelet/lipgloss)**, imported as `charm.land/lipgloss/v2`, for
  styling text and boxes.

bloom isn't built for Bubble Tea v1. Its views are `tea.View` values, and its mouse routing uses the `OnMouse`
handler that v2 views have.

## Install

```console
go get bloomfx.dev/bloom@latest
```

That gets all of bloom's packages. Import the ones you use:

```go
import (
	"bloomfx.dev/bloom"
	"bloomfx.dev/bloom/anim" // animated values, for transitions
	"bloomfx.dev/bloom/fx"   // effects, for transitions and backdrops
	tea "charm.land/bubbletea/v2"
	"charm.land/lipgloss/v2"
)
```

<Callout type="warn" title="Expect breaking changes">
  bloom is pre-1.0, and its API may still change significantly before v1.0.0. Pin the version in your
  `go.mod` and read the release notes before upgrading.
</Callout>

## Check that it works

This program prints a two-column layout and exits. It uses `bloom.Render`, which turns a layout into a string
without running a Bubble Tea program, so it's an easy way to try layouts out.

```go
package main

import (
	"fmt"

	"bloomfx.dev/bloom"
	"charm.land/lipgloss/v2"
)

func main() {
	box := lipgloss.NewStyle().Border(lipgloss.RoundedBorder()).Padding(0, 1)

	fmt.Println(bloom.Render(50, 5, bloom.Row(
		bloom.Fixed(16, bloom.Box(box, bloom.Text("sidebar"))),
		bloom.Fill(bloom.Box(box, bloom.Text("content"))),
	)))
}
```

```console
$ go run .
╭──────────────╮╭────────────────────────────────╮
│ sidebar      ││ content                        │
│              ││                                │
│              ││                                │
╰──────────────╯╰────────────────────────────────╯
```
