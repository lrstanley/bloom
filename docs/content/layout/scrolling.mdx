title: Scrolling
description: Scroll content that is taller or wider than its space with Scroll, move it with keys and the mouse wheel, and show scrollbars that can be dragged and clicked.
---

bloom has three ways to show more than fits:

- [`Scroll`](#scroll-content) shows any child from an offset. It lays out all of the child, which is fine for an
  article, a help screen, or a form.
- A [viewport](/layout/viewports) shows the lines of a text buffer, laying out only those in sight, for logs, files,
  and other long text.
- A [list](/layout/lists) shows rows of components, building only those in view, for thousands of items.

All three work with the same [scrollbars](#show-a-scrollbar).

## Scroll content

`bloom.Scroll(child, offset)` gives a child as much height as it wants, and shows it starting `offset` rows down,
clipped to the space the scroll has. The offset is model state, so you decide how keys and the mouse wheel move
it:

```go
type model struct {
	ui     *bloom.Root
	offset int // rows scrolled
	// ...
}

func (m *model) layout() bloom.Child {
	return bloom.Box(panel, bloom.Scroll(bloom.Text(m.article).Style(prose), m.offset))
}
```

To move the offset with keys, and to clamp it so it doesn't scroll past the end, `Update` needs to know how tall
the scroll and its content are. [Sizes and positions in Update](/layout/sizes-in-update) shows how, with paging by
a screen at a time.

## Scroll with the mouse wheel

Put an [`on.Scroll`](https://pkg.go.dev/bloomfx.dev/bloom/on#Scroll) handler on the node the scroll is in,
so the wheel only scrolls what it's over. `dy` is `1` for each step down and `-1` for each step up:

```go
reader := bloom.Fill(bloom.Box(panel, bloom.Scroll(content, m.offset))).
	ID(paneReader).
	On(on.Scroll(func(_, dy int) tea.Cmd { m.offset += dy * 3; return nil }))
```

The handler runs just before `Update` gets the wheel event, so clamp the offset in `Update` as you do for
[keys](/layout/sizes-in-update#find-a-nodes-size-in-update).

Remember to turn on mouse reporting in `View` with `v.MouseMode = tea.MouseModeCellMotion`.

## Scroll sideways

`X(offset)` scrolls a `Scroll` sideways too: its child gets as much width as it wants, so long lines don't wrap,
and is shown from column `offset`. It's what you want for wide tables and code:

```go
bloom.Scroll(bloom.Text(m.log).ID(paneLog), m.offset).X(m.logX)
```

Without it, the child gets the scroll's width, as before.

## Show a scrollbar

`bloom.ScrollbarOf(id)` is a scrollbar for the `Scroll` that the node with that ID is in. It follows the scroll
from the layout, so it needs no state of its own. Put it on the right side of the box's border with
[`Edge`](/layout/text-and-boxes#put-titles-and-more-on-a-border), and it takes no space. It's only drawn while the
content is taller than its view, so when everything fits, the plain border shows:

```go
bloom.Box(panel, bloom.Scroll(bloom.Text(m.article).Style(prose).ID(paneArticle), m.offset)).
	Edge(bloom.Right, bloom.Stretch, bloom.ScrollbarOf(paneArticle))
```

```
╭──────────────╮
│there was a   │
│border, and   ┃
│the border was│
╰──────────────╯
```

`ScrollbarOf` a [list](/layout/lists#show-a-scrollbar)'s own ID follows it in items, and its `OnScroll` gets the
first item to show, for `Offset`. `ScrollbarOf` a [viewport](/layout/viewports)'s ID follows it in rows, and
without an `OnScroll` of its own, scrolls it with the viewport's.

For content that a component windows itself, such as the [Bubbles viewport](/layout/bubbles-components), give
`bloom.Scrollbar(total, visible, offset)` the numbers yourself:

```go
bloom.Scrollbar(m.viewport.TotalLineCount(), m.viewport.VisibleLineCount(), m.viewport.YOffset())
```

`Horizontal()` makes either one a row tall, for content scrolled sideways. Put it on the bottom of the border:

```go
bloom.Box(panel, bloom.Scroll(bloom.Text(m.log).ID(paneLog), 0).X(m.logX)).
	Edge(bloom.Bottom, bloom.Stretch, bloom.ScrollbarOf(paneLog).Horizontal())
```

Either one can also go beside the content, in a `Row`, or under it in a `Column` when horizontal, where it takes a
column or a row. `Thumb(glyph, style)` sets how the part for what's in view looks, `"┃"` by default, or `"━"`
when horizontal. `Track(glyph, style)` sets the rest, which is not drawn by default, so a border beneath it shows
through. A scrollbar's natural length is zero, so on a border use `Stretch`.

### Drag and click a scrollbar

`OnScroll(fn)` makes a scrollbar work with the mouse. `fn` gets the offset to scroll to, which you set in your
model as you do for keys:

```go
bloom.ScrollbarOf(paneArticle).OnScroll(func(offset int) tea.Cmd {
	m.offset = offset
	return nil
})
```

Pressing on the thumb and moving drags it, keeping the point you grabbed under the pointer. Pressing anywhere
else on the scrollbar jumps so the thumb is centered there, and holding the button down keeps dragging. The
scrollbar takes clicks only while it's drawn, so with nothing to scroll, clicks reach whatever is beneath it.

## Select text in a scroll

A selectable node inside a `Scroll` takes the text scrolled out of sight too, and the selection stays on its text as
it scrolls. Dragging past the scroll's edge scrolls it, through the `on.Scroll` handler on it. See
[Selecting and copying text](/input/selection#select-past-the-edge).
