## Show text

`bloom.Text(s)` shows a string, which may already contain ANSI styles. On its own it's drawn as is, and clipped
to the space it's given. Give it a Lip Gloss style with `Style` and it's rendered at the size of its node instead,
so long lines wrap and a background fills the whole node:

```go
bloom.Text(body)                                                   // clipped
bloom.Text(body).Style(lipgloss.NewStyle().Padding(0, 1))          // wraps inside 1 column of padding
bloom.Text(title).Style(lipgloss.NewStyle().Background(highlight)) // background fills the node
```

A width or height set on the style itself is kept, so `Style(s.Width(20))` is 20 columns wide wherever it's
placed.

### Keep text on one line

`Truncate` shows a single line, turning newlines into spaces and cutting the text short with "…" when it doesn't
fit. Padding and borders count against the width. It's what you want for status bars, titles, and list items:

```go
bloom.Text(path).Style(statusStyle).Truncate()
```

```
a long line…
```

For text that should scroll rather than be cut short, such as a long title in a focused list item, see
[`Marquee`](/motion/feedback-effects#scroll-text-that-doesnt-fit).

### Plain strings and components

Any value with a `View() string` method can go in a layout, so you don't need `Text` for your own components or
for [Bubbles](/layout/bubbles-components). `Text` is for plain strings, which don't have a method.

### Text from outside your program

A string can hold escape sequences that go to the terminal as they are instead of being drawn, such as an image
drawn with the Kitty graphics protocol or sixel. `Text` and `Viewport` drop them, along with any other sequence
that isn't a style or a hyperlink, so a log, a file, or a message you didn't write can't send commands to the
terminal. When you made all of the text yourself and it holds an image, mark it trusted to keep them:

```go
bloom.Text(picture).Trusted()
bloom.Viewport(buf).Trusted()
```

A component's view is drawn as it is, commands included, since that's how a component shows an image. If a
component shows text from outside your program, clean the text first with
[`canvas.Sanitize`](https://pkg.go.dev/github.com/lrstanley/bloom/canvas#Sanitize), or show it in a `Text` or
`Viewport` instead.

## Draw a box around a node

`bloom.Box(style, child)` draws a Lip Gloss style's frame around a child: its margins, border, padding, and
background. The child gets the space inside.

```go
panel := lipgloss.NewStyle().
	Border(lipgloss.RoundedBorder()).
	BorderForeground(lipgloss.Color("#6e6a86")).
	Padding(0, 1)

bloom.Box(panel, bloom.Column(title, body))
```

Use `Box` rather than calling `panel.Render(...)` yourself. A pre-rendered string has a fixed size, but a box
knows its frame and gives the right amount of space to its child at any size. A box given less space than its
own border and padding is left out, rather than drawn broken.

## Put titles and more on a border

`Edge(side, align, child)` draws a child over one side of a box's border, such as a title, a counter, or help
text, so it fits more on screen without taking space from what's inside:

```go
bloom.Box(panel, list).
	Edge(bloom.Top, bloom.Start, bloom.Text("secrets").Style(title)).
	Edge(bloom.Top, bloom.End, bloom.Text(fmt.Sprintf("%d/%d", m.selected+1, len(m.items)))).
	Edge(bloom.Bottom, bloom.Center, bloom.Text("? help").Style(muted))
```

```
╭─secrets───────────3/120─╮
│kv/app/db                │
│kv/app/redis             │
╰─────────? help──────────╯
```

On the top and bottom, a child is one row tall and kept a cell away from the corners. On the left and right, it's
one column wide, and a `Text` runs down the side, a character to a row. Children at `Start` and `End` go from that end inward, in the order you add them, one cell apart.
Children at `Center` share the middle of whatever is left, and a child at `Stretch` takes all of it. A child is
given no more room than is left, so a `Text` is clipped and a `Truncate`d one is cut short with "…", and a child
with no room isn't shown. A side with no border shows nothing.

Edge children are nodes like any other, so they can have IDs, [mouse handlers](/input/mouse), and hover styles.
Tabs on a border can be clicked:

```go
tabs := bloom.Row(
	bloom.Text("all").Style(tab).HoverStyle(onTab).On(on.Click(m.showAll)),
	bloom.Text("kv").Style(tab).HoverStyle(onTab).On(on.Click(m.showKV)),
).Gap(1)

bloom.Box(panel, list).Edge(bloom.Top, bloom.End, tabs)
```

Single characters make good buttons on any side. Several at `Start` go down the left side one after another, a
cell apart:

```go
for _, a := range actions { // such as + for new, ✎ for edit, ✕ for delete
	box = box.Edge(bloom.Left, bloom.Start, bloom.Text(a.glyph).Style(icon).HoverStyle(hot).On(on.Click(a.run)))
}
box = box.Edge(bloom.Right, bloom.Center, bloom.Text("LOGS").Style(label)) // L, O, G, S down the right side
```

```
╭─secrets────────╮
+kv/app/db       L
│kv/app/redis    O
✎kv/app/smtp     G
│kv/infra/vault  S
✕kv/infra/pki    │
╰────────────────╯
```

A [scrollbar](/layout/scrolling#show-a-scrollbar) can go on a border too, where it shows only while there's
more to scroll to, and can be dragged.

### Join lines to the border

`EdgeAt(side, at, child)` puts a child at an exact cell along a side, counted from the top or left end, where `0`
is the corner. A negative `at` counts back from the other end, so `-1` is the far corner. It's for joining lines
drawn inside a box to its border, such as where column separators meet it, or for swapping a corner for a `├`
where two boxes stack:

```go
box := bloom.Box(panel, table)
for _, x := range separators { // the column of each │ inside, from the box's left edge
	box = box.
		EdgeAt(bloom.Top, x, bloom.Text("┬").Style(border)).
		EdgeAt(bloom.Bottom, x, bloom.Text("┴").Style(border))
}
box = box.Edge(bloom.Top, bloom.Start, bloom.Text("jobs").Style(title))
```

```
╭─jobs─┬──────┬─────╮
│   12 │ api  │ ok  │
│   13 │ db   │ ok  │
╰──────┴──────┴─────╯
```

Children placed with `EdgeAt` take no room from those placed with `Edge`, so a title or a counter stays where it
was. Edge children are drawn in the order you add them, so add the junctions first to let a title cover any under
it. A child gets the room from its cell to the end of the side, and a cell past the end, or a side with no
border, shows nothing.

## Animate a border

`BorderFx(t, effects...)` applies [effects](/reference/effects#borders) to a box's frame, its border, padding, and
background, leaving what's inside it and on its edges alone. The border effects in `fx` loop: `t` is the phase,
such as from [`anim.NewLoop`](/motion/animating-values), and they look the same at 0 and 1, so the loop is
seamless:

```go
type model struct {
	ui    *bloom.Root
	phase anim.Sequence // anim.NewLoop(4 * time.Second), started with m.phase.Loop() in Init
	// ...
}

bloom.Box(panel, list).BorderFx(m.phase.Float(), fx.Chase{From: accent, To: pink})
```

The [borders example](https://github.com/lrstanley/bloom/tree/master/_examples/borders) puts it all together:

![The borders example: a list with a title, clickable filter tabs, its position, and icon buttons on its border, its scrollbar being dragged and clicked, a log scrolled sideways with a horizontal scrollbar and its name down its side, next to boxes looping each border effect](/demos/borders.webp)

To draw a static gradient, use Lip Gloss's own `BorderForegroundBlend` in the box's style. `fx.Chase` is for a
gradient that moves, which would otherwise mean rendering the whole frame again on every frame.

## Center a node

`bloom.Centered(child)` places a child at its natural size in the middle of its space:

```go
bloom.Centered(bloom.Box(panel, bloom.Text("hi")))
```

```
        ┌──┐
        │hi│
        └──┘
```

## Align children across a row or column

In a row, children stretch to the row's full height by default, and in a column, to its full width. `Align`
changes that, for every child of the row or column:

```go
bloom.Row(sidebar, content).Align(bloom.Start) // each child at its natural height, at the top
```

Or for one slot only:

```go
bloom.Row(
	bloom.Fixed(10, tall),
	bloom.Auto(badge).Align(bloom.Center), // vertically centered next to tall
)
```

The values are `bloom.Stretch` (the default), `bloom.Start`, `bloom.Center`, and `bloom.End`.

## Justify children along a row or column

When no child grows, there may be space left over along the row or column. `Justify` decides where it goes,
using the values from the [`flex`](https://pkg.go.dev/github.com/lrstanley/bloom/flex#Justify) package:

```go
import "github.com/lrstanley/bloom/flex"

bloom.Row(a, b).Justify(flex.SpaceBetween)
```

```
┌─┐                        ┌─┐
│a│                        │b│
└─┘                        └─┘
```

| Value | Leftover space goes |
| --- | --- |
| `flex.Start` | after the children (the default) |
| `flex.Center` | equally before and after them |
| `flex.End` | before them |
| `flex.SpaceBetween` | between the children, none at the edges |
| `flex.SpaceAround` | around each child, so the edges get half as much as between children |
| `flex.SpaceEvenly` | equally between children and at both edges |

## Space children evenly

`Gap(n)` puts `n` cells between each pair of children:

```go
bloom.Row(cancel, save).Gap(2)
bloom.Column(fields...).Gap(1)
```

A slot that can never have any cells, such as `Fixed(0, ...)` or one that has collapsed, doesn't get a gap, so
hiding a child doesn't leave a double gap behind.
